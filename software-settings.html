软件设置

基础设置

调整课表窗口的显示方式、倒计时和多周轮换。

组件设置

管理组件的显示位置、顺序和专属选项。课表组件包含每节课的倒计时。

布局与组件

从组件库拖动卡片到任意一行，可重复放置同一种组件；点击已放置的卡片可编辑当前实例。

样式设置

编辑 CSS 自定义属性和主界面样式。保存后主界面会自动刷新。

使用 JSON 对象格式，例如 {"--center-font-size":"43px"}。

这里的内容会直接写入主界面 CSS 文件，可修改颜色、字体、间距和其他规则。

提醒

在主界面触发提醒遮罩：遮罩会覆盖课表组件并从中央扩散展开。

遮罩为不透明纯色，文字以白色显示；修改后自动保存，主界面刷新后生效。

点击按钮后，遮罩从课表组件中央扩散展开并显示提醒文字，5 秒后自动结束；点击遮罩可提前关闭。
